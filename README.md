<h2 align="center"> 👑 NOTE IMPORTANTE 👑 </h2>

- **Le Session ID n'est pas obligatoire, le bot nécessite seulement la variable d'environnement BOT_NUMBER.**
- **Après avoir ajouté ton numéro (237674073940) dans le fichier .env, déploie simplement le bot.**
- **Il affichera un code de jumelage (Pairing Code) à la fin du déploiement.**
- **Lien ton WhatsApp avec ce code et commence à régner.**

## Installation Manuelle (Termux / Ubuntu)
```bash
apt update && apt upgrade -y
apt install -y webp git wget curl ffmpeg imagemagick
curl -fsSl [https://deb.nodesource.com/setup_20.x](https://deb.nodesource.com/setup_20.x) | bash - && apt install -y nodejs
git clone [https://github.com/wambabrayan806-source/GLOBAL-XMD](https://github.com/wambabrayan806-source/GLOBAL-XMD)
cd GLOBAL-XMD
npm install
node index --pairing-code
